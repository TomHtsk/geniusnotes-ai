Tips

  • Commands appear in the preview panel as you type — press Enter or Space to confirm.
  • Commands run on the entire note. For selection-based actions, highlight the text first.
  • Results open in a new note tab so your original is never overwritten.
  • /format accepts a sub-command: /format code, /format academic, /format email.
  • Use the toolbar Study Tools menu as an alternative to typing commands.
